# 초안 본문

## Tide 개인정보처리방침

최종 수정일: [확인 필요 — 게시일]

Tide(이하 "서비스")는 화면 캡처 한 장에서 할 일을 만들어 주는 서비스이며, 웹과 데스크톱 앱(Windows·macOS)으로 제공됩니다. 이 방침은 서비스가 어떤 정보를 어떻게 다루는지 설명합니다.

운영 주체: [확인 필요 — 사업자명]
문의: [확인 필요 — 이메일]

### 1. 수집하는 정보

**가. 계정 정보**

- 이메일 주소
- Google 계정으로 로그인한 경우 Google이 제공하는 식별자와 이메일 주소

**나. 사용자가 캡처한 화면 이미지**

- 사용자가 전역 단축키를 눌러 직접 선택한 화면 영역의 이미지입니다.
- 🔴 **캡처한 영역에는 사용자가 선택한 무엇이든 담길 수 있습니다.** 화면에 열려 있던 메일·메시지·문서가 포함될 수 있으므로, 민감한 내용이 보이는 상태에서는 캡처하지 않기를 권합니다.
- 이미지는 할 일을 만들거나 완료 처리하기 위한 분석에만 쓰입니다.

**다. 캡처와 함께 전송되는 정보**

- 캡처한 시각
- 사용자의 시간대(예: `Asia/Seoul`) — "내일"처럼 상대적인 날짜를 해석하는 기준으로 쓰입니다
- 요청 종류(생성 또는 완료)

**라. 서비스 이용 중 만들어지는 정보**

- 할 일의 제목·설명·마감·태그, 그리고 그렇게 판단한 근거 한 문장
- 처리 기록(작업 로그) — 언제 무엇을 만들었거나 완료했는지

### 2. 이용 목적

- 캡처한 이미지를 분석해 할 일을 만들거나 완료 처리하기 위해
- 사용자의 할 일 목록과 처리 기록을 보여 주기 위해
- 로그인 상태를 유지하기 위해

서비스는 위 목적 외에 정보를 이용하지 않으며, **광고 목적으로 이용하거나 판매하지 않습니다.**

### 3. 캡처 이미지의 처리와 보관

- **서버는 캡처 이미지를 저장하지 않습니다.** 분석에 사용한 뒤 보관하지 않습니다.
- **데스크톱 앱도 이미지를 남기지 않습니다.** 캡처는 전송을 위해 임시 파일로만 존재하고, 전송이 끝나면 즉시 삭제됩니다.
- Windows에서는 캡처가 Windows 캡처 도구를 거치기 때문에, 캡처한 이미지가 **사용자 컴퓨터의 클립보드에 남습니다.** 이는 Windows의 동작이며 다른 내용을 복사하면 대체됩니다.
- 🔴 이미지 분석에는 [확인 필요 — AI 제공자명]의 모델을 이용하며, 분석을 위해 이미지가 해당 제공자에게 전송됩니다. [확인 필요 — 해당 제공자의 학습 이용 여부와 보관 정책]

### 4. 데스크톱 앱이 사용자 컴퓨터에 저장하는 것

서비스 계정과 별개로, 앱은 아래를 **사용자 컴퓨터 안에만** 저장합니다. 서버로 전송하지 않습니다.

| 저장되는 것 | 위치(Windows 기준) | 설명 |
|---|---|---|
| 로그인 토큰 | 운영체제의 보안 저장소 | 로그인 유지용. 로그아웃하면 삭제됩니다 |
| 대시보드 로그인 쿠키 | `%LOCALAPPDATA%\Tide\WebView2` | 앱 안에서 대시보드를 보기 위한 브라우저 데이터 |
| 진단 로그 | `%APPDATA%\Tide\Tide\tide.log` | 아래 참고 |

**진단 로그**에는 앱 버전, 캡처 시도와 전송 결과, 서버 응답 코드, 앱이 연 페이지 주소, 그리고 **알림으로 표시된 할 일 제목**이 기록됩니다. 문제를 파악하기 위한 것이며 자동으로 전송되지 않습니다. 파일을 직접 삭제해도 됩니다.

### 5. 제3자 제공

서비스는 아래 경우를 제외하고 개인정보를 제3자에게 제공하지 않습니다.

- 캡처 이미지 분석을 위한 AI 제공자에게 전송 (3항 참고)
- 서비스 운영에 필요한 인프라 제공자 [확인 필요 — 호스팅·데이터베이스·인증 제공자]
- Google 계정으로 로그인하는 경우, 로그인 처리를 위해 Google과 주고받는 정보
- 법령에 따라 요구되는 경우

### 6. 보관 기간

- 계정과 관련 데이터는 서비스를 이용하는 동안 보관합니다.
- **회원 탈퇴 시 할 일·태그·처리 기록이 삭제됩니다.**
- 캡처 이미지는 애초에 보관하지 않습니다(3항).
