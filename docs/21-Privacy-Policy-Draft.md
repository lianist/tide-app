# Tide 개인 정보 보호 정책

최종 업데이트: [확인 필요 — 게시일]

Tide는 사용자가 Tide와 상호 작용하는 과정과 Tide 제품을 사용하는 과정에서 사용자로부터 데이터를 수집합니다. 이 중 일부는 사용자가 직접 제공하며, 일부는 사용자가 제품을 사용하는 과정에서 수집됩니다.

Tide는 화면의 일부를 캡처하면 그 내용을 분석해 할 일을 만들거나 완료 처리하는 서비스이며, 웹과 데스크톱 앱(Windows·macOS)으로 제공됩니다.

## Tide가 수집하는 개인 데이터

Tide는 사용자가 제공하는 데이터와 사용자가 제품을 사용하는 과정에서 생성되는 데이터를 수집합니다. 수집하는 데이터의 종류는 사용자가 사용하는 기능에 따라 달라집니다.

Tide가 수집하는 데이터는 다음과 같습니다.

- **계정 데이터** — 사용자가 계정을 만들 때 제공하는 전자 메일 주소. Google 계정으로 로그인하는 경우 Google이 제공하는 계정 식별자와 전자 메일 주소.
- **캡처한 화면 이미지** — 사용자가 전역 바로 가기 키를 눌러 직접 선택한 화면 영역의 이미지. 이 이미지는 할 일을 만들거나 완료 처리하기 위한 분석에만 사용됩니다.
- **캡처와 함께 전송되는 데이터** — 캡처한 시각, 사용자의 시간대(예: `Asia/Seoul`), 사용자가 선택한 요청 종류(생성 또는 완료). 시간대는 "내일"과 같은 상대적 날짜를 해석하는 기준으로 사용됩니다.
- **서비스 이용 중 생성되는 데이터** — 할 일의 제목·설명·마감·태그, 그렇게 판단한 근거, 그리고 언제 무엇을 만들었거나 완료했는지에 대한 처리 기록.

**캡처한 이미지에 포함될 수 있는 내용** — 캡처 영역은 사용자가 직접 선택하며, 그 영역에 표시된 모든 내용이 이미지에 포함됩니다. 화면에 열려 있던 전자 메일, 메시지, 문서가 함께 담길 수 있습니다. 민감한 정보가 표시된 상태에서는 캡처하지 않을 것을 권장합니다.

## Tide가 개인 데이터를 사용하는 방법

Tide는 수집한 데이터를 제품을 제공하고 운영하는 데 사용합니다. 구체적으로 다음 목적으로 사용합니다.

- 캡처한 이미지를 분석하여 할 일을 만들거나 완료 처리하기 위해
- 사용자의 할 일 목록과 처리 기록을 표시하기 위해
- 사용자의 로그인 상태를 유지하기 위해

Tide는 위 목적 외의 용도로 개인 데이터를 사용하지 않으며, **광고 목적으로 사용하거나 판매하지 않습니다.**

## Tide가 개인 데이터를 공개하는 이유

Tide는 사용자의 동의가 있거나 제품을 제공하기 위해 필요한 경우에 한해 개인 데이터를 공유합니다. 데이터를 공유하는 경우는 다음과 같습니다.

- **이미지 분석을 위한 인공 지능 제공자** — 캡처한 이미지를 분석하기 위해 [확인 필요 — 제공자명]에 전송합니다. 자세한 내용은 아래 "인공 지능 기능"을 참조하십시오.
- **서비스 운영에 필요한 인프라 제공자** — [확인 필요 — 호스팅·데이터베이스·인증 제공자]
- **Google** — 사용자가 Google 계정으로 로그인하는 경우, 로그인 처리를 위해 Google과 데이터를 주고받습니다.
- **법령에 따른 요구** — 법령에 따라 공개가 요구되는 경우

## 사용자의 개인 데이터에 대한 액세스 및 제어 방법

사용자는 Tide가 보유한 데이터를 직접 확인하고 삭제할 수 있습니다.

- **할 일과 태그** — 대시보드에서 직접 수정하거나 삭제할 수 있습니다.
- **로그인 정보** — 앱에서 로그아웃하면 사용자 컴퓨터에 저장된 로그인 토큰이 삭제됩니다.
- **앱이 컴퓨터에 저장한 데이터** — 앱을 제거하면 함께 삭제됩니다.
- **계정 삭제** — 계정을 삭제하면 할 일, 태그, 처리 기록이 삭제됩니다.
- 그 밖의 요청은 [확인 필요 — 연락처]로 문의하십시오.

## 쿠키 및 유사 기술

Tide는 로그인 상태를 유지하기 위해 쿠키를 사용합니다.

데스크톱 앱은 대시보드를 앱 안에서 표시하기 위해 내장 브라우저를 사용하며, 그 브라우저가 로그인 쿠키를 사용자 컴퓨터에 저장합니다. 이 데이터는 사용자 컴퓨터를 벗어나지 않습니다. 저장 위치는 아래 "Tide 데스크톱 앱"을 참조하십시오.

Tide는 광고 또는 추적 목적의 쿠키를 사용하지 않습니다.

## Tide 계정

Tide 계정은 사용자의 할 일과 처리 기록을 사용자에게 연결하는 수단입니다. 계정을 만들려면 전자 메일 주소가 필요하며, Google 계정으로 대신할 수 있습니다.

웹과 데스크톱 앱은 각각 별도의 로그인 상태를 유지합니다. 한쪽에서 로그아웃해도 다른 쪽의 로그인은 유지됩니다.

## 어린이로부터의 정보 수집

Tide는 어린이를 대상으로 하지 않으며, 어린이로부터 의도적으로 개인 데이터를 수집하지 않습니다. [확인 필요 — 연령 기준을 둘 것인지]

- **캡처한 이미지는 보관하지 않습니다.** 자세한 내용은 아래 "Tide 데스크톱 앱"을 참조하십시오.

## 인공 지능 기능

Tide의 핵심 기능은 인공 지능으로 동작합니다. 사용자가 캡처한 이미지를 모델이 분석하여 할 일의 제목, 마감, 태그와 그렇게 판단한 근거를 생성합니다.

- **이미지가 전송됩니다** — 분석을 위해 캡처한 이미지가 [확인 필요 — 제공자명]에 전송됩니다. Tide 서버가 이미지를 저장하지 않더라도 분석을 위한 전송은 이루어집니다.
- **제공자의 데이터 처리** — [확인 필요 — 해당 제공자가 전송된 데이터를 모델 학습에 사용하는지 여부와 보관 정책]
- **생성된 내용** — 모델이 생성한 할 일의 제목과 근거는 사용자 계정에 저장되며, 사용자가 직접 수정하거나 삭제할 수 있습니다.
- **정확성** — 생성된 내용은 이미지에 대한 모델의 해석이며 사실과 다를 수 있습니다.

## Tide 데스크톱 앱

이 섹션은 Windows 및 macOS용 Tide 앱에만 해당합니다.

**캡처한 이미지의 처리**

- **Tide 서버는 캡처한 이미지를 저장하지 않습니다.** 분석에 사용한 후 보관하지 않습니다.
- **앱도 이미지를 남기지 않습니다.** 캡처한 이미지는 전송을 위해 임시 파일로만 존재하며, 전송이 끝나면 즉시 삭제됩니다.
- **Windows에서는 캡처한 이미지가 클립보드에 남습니다.** Windows에서 캡처는 Windows 캡처 도구를 통해 이루어지며, 그 결과가 클립보드를 거쳐 앱에 전달되기 때문입니다. 이는 Windows의 동작이며, 다른 내용을 복사하면 대체됩니다.

**앱이 사용자 컴퓨터에 저장하는 데이터**

다음 데이터는 사용자 컴퓨터에만 저장되며 Tide 서버로 전송되지 않습니다.

- **로그인 토큰** — 운영 체제의 보안 저장소에 저장됩니다. 로그아웃하면 삭제됩니다.
- **대시보드 로그인 쿠키** — 앱 안에서 대시보드를 표시하기 위한 내장 브라우저 데이터입니다. Windows에서는 `%LOCALAPPDATA%\Tide\WebView2`에 저장됩니다.
- **진단 로그** — Windows에서는 `%APPDATA%\Tide\Tide\tide.log`에 저장됩니다. 앱 버전, 캡처 시도와 전송 결과, 서버 응답 코드, 앱이 연 페이지 주소, 그리고 **알림으로 표시된 할 일 제목**이 기록됩니다. 문제 확인을 위한 것이며 자동으로 전송되지 않습니다. 사용자가 직접 삭제할 수 있습니다.

**전역 바로 가기 키**

앱은 사용자가 캡처를 시작할 수 있도록 전역 바로 가기 키를 등록합니다. 앱은 해당 키 조합이 눌렸는지만 확인하며, 사용자의 다른 키 입력을 수집하지 않습니다.
